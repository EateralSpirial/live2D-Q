# 03｜功能介绍与基础使用说明

本文面向不熟悉音频、AI 模型或 OBS 的用户。当前仓库仍处于“实现规格”阶段；以下说明描述成品应提供的使用方式。Codex 实现后，命令和截图需要按实际版本更新。

## 1. 这个项目会做什么

角色不需要摄像头。程序会监听你选择的麦克风，并把声音分成几类信号：

- **口型信号**：判断当前更接近“啊、衣、乌、诶、哦、闭唇”等形状；
- **说话强度**：让嘴巴开合、身体轻微起伏；
- **音高和语速**：让头部、眉眼、头发和披风有细微变化；
- **语音识别**：显示当前转写文字，可用于字幕；
- **情绪识别**：在高兴、认真、惊讶、疲惫等预设之间平滑切换；
- **手动控制**：你可以锁定表情、切换手势或关闭某项自动动作。

直播画面由一个透明网页提供给 OBS。控制面板在普通浏览器中打开，不会被 OBS 捕获。

## 2. 第一次使用前需要准备

- Windows 11；
- NVIDIA 显卡驱动正常；
- OBS Studio；
- 一个可用的麦克风；
- 已生成并验证的角色资产；
- 已按安装脚本下载的语音模型；
- 普通浏览器（Edge 或 Chrome）。

安装细节见 `08_WINDOWS_11_SETUP.md`。

## 3. 启动流程

成品版本应提供：

```powershell
./scripts/start.ps1
```

启动器会：

1. 检查依赖；
2. 启动语音服务；
3. 启动 WebUI；
4. 打开控制页面；
5. 显示可复制到 OBS 的 overlay 地址。

启动后，首页应显示以下状态：

- WebUI：已连接；
- 渲染器：已加载角色；
- 麦克风：未选择/已连接；
- 口型引擎：wLipSync/回退模式；
- 语音模型：加载中/已就绪/已关闭；
- OBS overlay：已连接/未连接；
- 当前 FPS、音量和推理延迟。

## 4. 选择麦克风

进入“音频”页面：

1. 点击“允许麦克风”；
2. 从设备列表选择实际使用的麦克风；
3. 对着麦克风正常说话；
4. 确认电平条会移动；
5. 调整输入增益，使正常说话大多位于绿色区；
6. 静音时调整噪声门，使嘴巴能闭合；
7. 不确定时先保持浏览器的回声消除、降噪和自动增益为默认值，再逐项测试。

### 麦克风电平建议

- 静音时不应持续触发说话；
- 正常说话不应长期顶满；
- 爆音时可以短暂进入高电平，但不应削波；
- 使用 OBS 同一个麦克风时，确认没有被独占模式占用。

## 5. 口型校准

第一次使用 wLipSync，需要建立与你声音匹配的 profile。

进入“口型 → 校准向导”：

1. 保持与直播相同的麦克风距离；
2. 按提示持续发“啊”；
3. 依次录制“衣、乌、诶、哦”；
4. 可选录制闭唇“姆/吧/啪”和“夫”；
5. 每个样本可试听、重录；
6. 校准完成后进行自动测试；
7. 保存为命名 profile，例如 `main-mic-normal-voice`。

### 测试口型

控制页提供手动按钮：

- REST/闭嘴；
- A；
- I；
- U；
- E；
- O；
- MBP；
- FV。

先确认每张口型图位置完全一致，再测试自动识别。

### 常见调整

- 嘴巴太迟钝：提高敏感度或缩短 Attack；
- 闭嘴太慢：缩短 Release；
- 静音仍张嘴：提高噪声门或静音闭合阈值；
- 口型乱跳：增加视素平滑和主导保持；
- 所有元音都像 A：重新校准并降低 A 的增益；
- 爆破音不闭唇：提高 MBP 权重或启用 ASR 辅助。

## 6. 语音识别和字幕

进入“ASR/字幕”：

- 开启或关闭语音识别；
- 语言可选自动、普通话、粤语、英语、日语、韩语；
- 查看 partial 和 final 文字；
- 设置字幕保留时间、最大行数和字体；
- 决定字幕是否输出到 overlay；
- 添加常用专有名词或热词；
- 查看推理时间和置信度。

口型不依赖字幕。即使关闭 ASR，wLipSync 仍可工作。

## 7. 情绪和表情

进入“情绪”：

- 开启自动情绪；
- 选择置信度阈值；
- 设置最短保持时间；
- 调整 neutral 偏置；
- 选择允许自动触发的表情；
- 为每种情绪设置动作强度；
- 使用“锁定当前表情”暂停自动切换。

### 推荐默认行为

| 情绪/状态 | 角色表现 |
|---|---|
| neutral | 平静微笑、正常眨眼、轻微呼吸 |
| happy | 眉眼上扬、笑眼概率增加、星光略强 |
| excited | 动作幅度提高、披风和头发更活跃 |
| thoughtful | 视线略下、动作减弱、头部轻偏 |
| serious | 眉毛略压、身体更稳定、嘴型更紧 |
| angry | 只做克制的眉眼和紧张嘴，不做夸张抖动 |
| sad | 眼睑略低、动作和光效减弱 |
| surprised | 短促睁眼、眉毛抬高、轻微后仰 |
| tired | 半睁眼、眨眼变慢、动作减弱 |
| confused | 头部轻偏、眉毛不对称、可选问号 FX |

情绪识别不是读心。它只根据声音特征做概率判断，因此手动锁定和调整阈值是正常使用的一部分。

## 8. 头发、披风和身体动作

进入“动作/物理”：

- **呼吸**：持续缓慢的身体起伏；
- **说话弹性**：音节起始时的轻微点头或身体脉冲；
- **头发柔软度**：越高越飘，越低越稳；
- **头发阻尼**：越高越快停止；
- **披风幅度**：控制星云披袖的摆动；
- **语速联动**：说得快时物理略增强；
- **音量联动**：说得响时动作略增强；
- **最大幅度**：防止角色抽动；
- **随机视线**：无摄像头时让角色偶尔看向不同方向；
- **自动眨眼**：设置间隔、双眨概率和困倦模式。

建议先使用默认预设，再逐项调整。头发资产较多时，过高的柔软度会造成穿插。

## 9. 手动表情、动作和热键

控制页应提供：

- 一键 neutral；
- 思考、认真、轻笑、吐槽、惊讶、疲惫、高光觉醒；
- 左手展示/放下；
- 右手挥手；
- 星光开关；
- 眨眼/单眼眨眼；
- 暂停自动情绪；
- 暂停所有自动动作；
- 紧急静音/闭嘴。

每个预设都可以绑定键盘热键。热键冲突时，UI 应给出提示。

## 10. 加入 OBS

### 10.1 添加 Browser Source

1. 启动本项目；
2. 在控制页复制 overlay URL；
3. 打开 OBS；
4. 在“来源”中点击 `+`；
5. 选择“浏览器”；
6. 新建来源；
7. 粘贴 URL；
8. 设置宽高；
9. 勾选自定义帧率并设为 60；
10. 确认背景透明；
11. 把角色源放在直播背景上方。

建议初期不要启用“不可见时关闭源”，这样切换场景时不会重新初始化角色。稳定后再测试该选项。

### 10.2 检查透明边缘

控制页提供黑、白和棋盘格测试背景。依次查看：

- 头发粉色边缘是否有白边；
- 星云披风半透明区域是否有黑边；
- 发光特效是否被裁切；
- 额饰细线是否闪烁；
- 星星 FX 周围是否带粉色背景残留。

### 10.3 声音与嘴型同步

若观众感觉声音比嘴巴更早：

- 在 OBS 的麦克风高级音频属性中增加同步偏移；
- 从 60–100 ms 开始测试；
- 使用系统提供的“啪/拍手”延迟测量模式；
- 不要盲目把延迟加到几百毫秒。

## 11. 配置与预设

建议保存三类配置：

- **角色配置**：资产、绘制顺序、物理、表情映射；
- **音频配置**：设备、增益、噪声门、口型 profile；
- **场景配置**：OBS、尺寸、FPS、特效和热键。

控制页应提供：

- 自动保存；
- 手动另存为；
- 导出 JSON/YAML；
- 导入前预览差异；
- 恢复默认；
- 版本迁移；
- 损坏配置备份。

## 12. 诊断页面

遇到问题时先查看：

- 麦克风权限；
- 当前设备 ID；
- AudioContext 状态；
- wLipSync profile 是否加载；
- PCM 发送速率；
- speech-service 健康状态；
- ASR/情绪推理耗时；
- WebSocket 延迟和重连次数；
- overlay FPS；
- WebGL 错误；
- CPU、GPU、VRAM；
- 资产缺失或 alpha 警告。

“导出诊断包”不应包含原始录音、OBS 密码或完整转写文本，除非用户显式勾选。

## 13. 常见问题

### 角色完全不动

- 检查 overlay 是否加载角色；
- 检查控制页与服务端连接；
- 点击手动参数测试；
- 检查是否开启“暂停所有自动动作”。

### 嘴巴不动

- 浏览器是否有麦克风权限；
- AudioContext 是否因浏览器策略处于 suspended；
- profile 是否有效；
- 音量门是否过高；
- 切到音量回退模式测试。

### OBS 显示粉色背景

- 可能加载了参考图而不是 overlay；
- 检查 overlay CSS 和渲染器 clear alpha；
- 角色资产是否仍包含背景；
- 使用 alpha 测试页定位。

### 口型和声音不同步

- 先看控制页的本地延迟；
- 检查系统降噪和蓝牙设备造成的音频延迟；
- 在 OBS 给麦克风增加小幅同步偏移；
- ASR 辅助模式会增加延迟，可切回快速模式。

### 情绪总是判断错误

- 提高置信度阈值；
- 增加 neutral bias；
- 增加最短保持时间；
- 关闭某些自动情绪；
- 使用手动锁定；
- 情绪模型只根据声音，不理解完整语义。

### 角色动作太大或穿模

- 降低音量/语速联动；
- 降低头发和披风幅度；
- 增加阻尼；
- 降低头部 X/Y/Z 范围；
- 运行资产遮挡区检查。

### speech-service 加载模型失败

- 查看模型路径和许可证确认记录；
- 检查显卡驱动；
- 检查 Python 环境是否与 See-through 混用；
- 运行 `scripts/doctor.ps1`；
- 临时关闭 ASR/情绪，口型仍应可用。

## 14. 隐私说明

核心设计以本地处理为主：

- 麦克风音频只发送到 localhost 服务；
- 默认不保存录音；
- 默认不上传转写和情绪结果；
- 模型首次下载可能需要访问其官方托管站；
- UI 应明确显示当前是否有调试录制或外网请求。
