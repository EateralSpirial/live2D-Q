# 09｜角色视觉风格与生成约束

本文用于约束 Codex、图像生成子代理和资产修复流程。所有资产必须以本地完整源图 `assets/reference/local/character_reference_source.png` 为主图参考；GitHub 中的 [`character_reference_preview.webp`](../assets/reference/character_reference_preview.webp) 仅用于文档预览。不得根据文字描述重新设计一个“相似角色”。

## 1. 角色定位

- Q 版、男性偏中性；
- 气质清透、理性、内省、温和但略有疏离；
- 可爱，但不要幼儿化、女性化或夸张卖萌；
- 视觉重点是头发层次、深邃眼睛、星形额饰和星云披袖；
- 动态重点是头发、五官、表情和少量轻动作；
- 身体资产保持简单，避免为复杂全身动作大量重绘。

## 2. 主图中的固定造型

### 2.1 头发

- 浅粉色至粉白色；
- 发量较多，柔软蓬松，长度约至肩部/上背；
- 顶部有自然分缝和两束轻微翘起的发丝；
- 刘海覆盖额头但不遮住全部眼睛；
- 侧发和后发有多层外翻发梢；
- 高光是柔和珍珠白，不做金属或荧光质感；
- 轮廓线为偏玫红的粉色线稿，粗细需与主图一致。

### 2.2 眼睛

- Q 版大眼，但保持聪明、沉静而不是纯幼态；
- 瞳色为深红、深紫、深蓝交织；
- 下部有红粉色光泽，上部偏深蓝紫；
- 瞳孔、星点与多个高光形成深邃晶体感；
- 上睫毛较粗、黑蓝色；下眼线轻；
- 左右眼大小、角度、瞳孔位置必须严格对称并与主图一致。

### 2.3 面部

- 柔和圆润的 Q 版脸型；
- 下巴不可尖锐；
- 肤色浅，阴影为很淡的粉色；
- 默认嘴为小幅、克制的微笑；
- 鼻子极简，不增加写实鼻梁；
- 表情差分不能改变脸型或眼睛基础位置。

### 2.4 额饰

- 细金色链条横跨额头；
- 链上分布蓝紫色星形小饰物；
- 中央为较大的蓝紫晶体星；
- 中央星下方有金色结构和蓝色小吊坠；
- 必须分层，链条、中央星和吊坠可独立轻摆；
- 不得改成王冠、发箍、花环或金属头盔。

### 2.5 服装

- 内层为白色/粉白色简洁衣装；
- 外侧宽袖/披风呈蓝、青绿、少量紫色的深空星云；
- 星云中有细小星点、亮星和柔和渐变；
- 金色线条是服装视觉骨架，象征理性与太阳；
- 深蓝领口、腰带和鞋子提供结构；
- 腰部为金色圆环星盘，中心粉紫星；
- 衣服不能改成机甲、厚重盔甲、传统西装或明显女裙。

### 2.6 身体比例与姿势

- 大头短身的 Q 版比例；
- 默认主图姿势：画面左侧手臂抬起并张开手掌，画面右侧手臂自然放下；
- 腿短、脚小，鞋子为深蓝短靴并带金色星形装饰；
- 生成差分时不改变头身比、肩宽和角色在画布中的位置。

### 2.7 装饰星星

- 主图背景有粉色和紫色的四角星；
- 运行时不保留粉色背景；
- 星星必须拆成独立 FX，可隐藏、闪烁、缩放；
- 不增加大量粒子遮挡人物。

## 3. 色彩约束

| 区域 | 主色 | 辅色 | 禁止漂移 |
|---|---|---|---|
| 头发 | 浅粉、粉白 | 珍珠白高光 | 洋红荧光、灰紫、纯白银发 |
| 眼睛 | 深蓝、深紫、深红 | 粉红高光 | 纯浅蓝、纯红、单色虹膜 |
| 皮肤 | 浅暖肤色 | 淡粉阴影 | 灰暗、黄褐、强对比写实阴影 |
| 内衬 | 白、粉白 | 深蓝领口 | 纯黑主衣、过度花纹 |
| 披袖 | 青绿、深蓝 | 紫色星云 | 纯紫、纯绿、赛博霓虹 |
| 线条/饰品 | 温暖金色 | 深蓝描边 | 银灰替代全部金线 |
| 鞋/腰带 | 深蓝 | 金色星形 | 黑红暗黑系 |

生成资产时优先从主图取色，不要仅凭文字估算色值。

## 4. 线稿和渲染

- 二次元 Q 版手绘感；
- 轮廓清晰，线条粗细与主图一致；
- 柔和赛璐璐上色加少量渐变；
- 不增加照片纹理、3D 渲染反光或复杂噪点；
- 星云纹理可以细致，但必须服从袖子轮廓；
- 每层的阴影方向、亮度和边缘必须与主图一致；
- 透明 PNG 使用干净 straight alpha，边缘不能混入粉色背景。

## 5. 表情基调

基础表情：平静、清透、轻微微笑。

允许的差分：

- 思考：视线略低、眉毛轻收、动作减弱；
- 认真：上眼睑略压、眉毛更有角度；
- 轻笑：嘴角上扬、笑眼或半笑眼；
- 冷静吐槽：半睁眼、嘴型克制；
- 惊讶：眼睛稍大、眉毛抬高、O 口；
- 疲惫：半睁眼、轻微眼下阴影；
- 高光觉醒：眼睛和胸口星盘发光、星点增强；
- 生气/严肃：保持克制，不做青筋、血红眼或夸张怒吼。

## 6. 禁止项

- 角色性别气质明显变成女性；
- 头发长度、分缝、刘海轮廓发生大幅改变；
- 下巴变尖；
- 眼睛变浅、变单色或丢失深红蓝紫层次；
- 星形额饰缺失、穿模或变成其他头饰；
- 星云袖变成纯色披风；
- 金色线条断裂或颜色漂移；
- 增加不在主图中的耳朵、动物特征、翅膀、武器或复杂机械件；
- 在运行时资产中保留粉色背景；
- 任何文字、水印、签名或 Logo；
- 局部资产单独裁切、缩放或改变画布坐标；
- 为不同口型重新生成整个脸，导致五官跳动。

## 7. 资产生成提示词模板

每个图像编辑任务至少包含以下约束：

```text
Use assets/reference/local/character_reference_source.png as the exact character and coordinate reference.
Edit only the requested component. Preserve the same 2048x2048 canvas, character scale,
pose, line weight, lighting, palette, and all unaffected geometry. Output a transparent RGBA PNG.
Complete the component under occluding layers with consistent inpainting so deformation will not reveal holes.
Do not add background, text, watermark, new accessories, or change gender presentation.
```

然后追加该资产的具体内容、可见区域、需要补全的遮挡区域和禁止包含的相邻部件。

## 8. 一致性验收

每批资产必须通过：

1. 与主图并排审查；
2. 默认合成图审查；
3. 黑/白/棋盘背景 alpha 审查；
4. 左右平移和轻微转头露洞审查；
5. 头发摆动穿插审查；
6. 表情切换时五官位置稳定审查；
7. 色板采样差异审查；
8. 禁止项自动/人工检查。
