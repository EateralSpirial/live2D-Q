# 05｜统一 WebUI 控制面板规格

本文定义总控制面板的完整功能集合。目标是保留 Anime2.5DRig 原有 UI 的优势，同时补齐音频、口型、ASR、情绪、参数总线、OBS、配置和诊断。

## 1. 设计原则

- **控制页与输出页分离**：`/control` 有 UI，`/overlay` 只有透明角色；
- **基础/高级双模式**：基础用户不需要面对全部参数；
- **实时反馈**：每项调节都能立即预览；
- **可回退**：模型失败时，基础口型、眨眼和 idle 仍可使用；
- **可观测**：延迟、FPS、模型状态和错误必须可见；
- **配置可迁移**：所有设置可以导入、导出、比较和恢复；
- **默认本地隐私**：无隐藏遥测，不默认保存录音；
- **宁可提供高级项，也不要把关键调参写死在代码中**。

## 2. 优先级定义

- **P0**：MVP 必须；
- **P1**：正式直播版本应有；
- **P2**：增强项，接口先预留；
- **DEV**：开发/诊断模式显示，普通用户默认隐藏。

## 3. 路由和页面

| 路由 | 优先级 | 页面 |
|---|---:|---|
| `/control` | P0 | 总控制台 |
| `/overlay` | P0 | OBS 透明角色，只读 |
| `/assets` | P0 | 资产加载、校验和预览 |
| `/calibrate/lipsync` | P0 | wLipSync 校准向导 |
| `/diagnostics` | P0 | 运行状态、延迟、日志、自检 |
| `/legacy-rig` | P1 | Anime2.5DRig 原始/高级绑定 UI |
| `/subtitle` | P1 | 独立透明字幕源 |
| `/remote` | P2 | 局域网只读/遥控页面，默认关闭 |

# 19. 默认预设

至少提供：

1. `balanced-60fps`：默认；
2. `low-latency`：更短口型平滑、关闭 ASR 辅助；
3. `high-quality-lipsync`：启用 ASR/CTC 辅助并允许额外延迟；
4. `quiet-room`：低噪声门；
5. `noisy-room`：更高噪声门和稳定性；
6. `calm-teacher`：动作小、头发稳、表情克制；
7. `expressive`：物理和 FX 增强，但有限幅；
8. `30fps-safe`：低性能模式；
9. `diagnostic`：显示状态但不用于直播。

# 20. UI 验收

- 基础用户能在 10 分钟内完成首次设置；
- 所有 P0 参数可通过 UI 修改且有默认值；
- 控制页刷新不会中断 overlay 超过合理重连时间；
- overlay 永远不显示控制 UI、错误对话框或日志；
- 所有滑块可重置；
- 配置导入有差异预览；
- 不可用功能显示原因和解决方法，而不是静默禁用；
- 高级模式关闭后，基础流程仍完整；
- 诊断包默认不包含录音、密码和完整转写。
